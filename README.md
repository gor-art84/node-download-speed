# Замер скорости скачивания

При успешном запуске скрипт делает ровно 10 последовательных GET-запросов по заданному адресу. Каждый следующий запрос начинается после полного чтения тела предыдущего ответа. Тело читается потоком, поэтому можно использовать большой файл.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется. В каталоге репозитория запустите команду и подставьте нужный HTTP(S)-адрес.

```sh
node download-speed.mjs "https://example.com/"
```

## Как считаются результаты

- **Среднее время запроса** в миллисекундах — сумма длительностей 10 запросов, делённая на 10. Замер идёт от начала запроса до полного чтения тела.
- **Минимальное и максимальное время запроса** в миллисекундах — самый короткий и самый длинный замеры из десяти.
- **Общий объём** в байтах — сумма размеров тел 10 ответов. При HTTP-сжатии учитываются байты после распаковки. Заголовки в объём не входят.
- **Средняя скорость** в МБ/с — общий объём, делённый на суммарное время запросов в секундах. Один мегабайт равен 1 000 000 байт.

Указывайте конечный URL. При перенаправлении скрипт выводит полученный HTTP-статус, например `HTTP 302`, и завершает работу с кодом 1. Тот же код завершения используется при других HTTP-ответах вне диапазона 2xx, обрыве соединения или превышении таймаута в 60 секунд. Сообщение содержит номер запроса, на котором произошла ошибка. Итоговая статистика выводится после десяти успешных запросов.
